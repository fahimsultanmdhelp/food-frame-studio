## About this repository

The whole website is one file: `index.html`. The CSS, JavaScript and sample images are inside it, so there is nothing else to upload. It is hosted for free with GitHub Pages.

## How to update the website

1. Edit or replace `index.html` on GitHub.
2. Press **Commit changes**.
3. Wait 1 to 2 minutes, then refresh the site.

Links and design samples are listed near the top of the `<script>` section in `index.html`.
